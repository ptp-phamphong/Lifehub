# Information AI Notes

This folder stores project guidance for future AI-assisted work.

Files:
- `01_tech-stack-and-versions.md`: database, backend, web frontend, and mobile stack with key package versions.
- `02_architecture-patterns.md`: backend and frontend design patterns currently used in the codebase.
- `03_deployment-guide.md`: deployment flow for database backup, backend, web frontend, and mobile app.
- `04_feature-system-info.md`: System Info feature (read Pi hardware status).
- `05_feature-expense-record-crud.md`: Expense Record CRUD with filtering, sorting, aggregation.
- `06_feature-reason-type-crud.md`: Reason Type settings CRUD.
- `07_feature-course-schedule-crud.md`: Course Schedule CRUD with Excel import.
- `08_feature-course-schedule-calendar.md`: Course calendar display (week/month views).
- `09_feature-notification-management.md`: Notification monitor + filter management (mobile-only).
- `10_feature-notification-listener-plugins.md`: Android native plugins for notification capture.
- `11_feature-other-and-missing.md`: Other features, platform gaps, and missing feature summary.
- `12_feature-income-record-crud.md`: Income Record CRUD (web + backend), with tab integration in expense-record-list route.
- `13_feature-semester-metadata-crud.md`: Semester metadata CRUD (web + backend) with current semester validation on Angular form.

Scope covered:
- Database: MySQL
- Backend: ASP.NET Core 8, C#, Entity Framework Core code-first
- Front-end web: Angular 16
- Front-end mobile: React Native with Expo, plus a small amount of Android native code generated by Expo config plugins

Important note:
- This documentation is based on the current codebase state in this repository, not on older project notes.
- The backend currently uses ASP.NET Core dependency injection in `Program.cs`.
